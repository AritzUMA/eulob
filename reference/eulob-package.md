# EU-LOB: European Union Lobbying Organizations Database

Provides tools for accessing and exploring a bundled catalogue of
registered lobbying organizations in the European Union.

## Details

The catalogue covers 19 territorial scopes and 21 registers, including
the supranational EU Transparency Register. The Netherlands is not
included in the searchable catalogue because its available historical
records do not support reliable identification of lobbying entities.

The catalogue distinguishes normalized organization names from
register-specific entity identifiers. Records are not globally
deduplicated legal entities.

Data are stored locally and can be queried without an internet
connection.

## Main functions

- [`eulob_countries()`](https://eulob.lobbyresearch.org/reference/eulob_countries.md):
  Territorial coverage.

- [`eulob_registers()`](https://eulob.lobbyresearch.org/reference/eulob_registers.md):
  Available registers.

- [`eulob_lobbies()`](https://eulob.lobbyresearch.org/reference/eulob_lobbies.md):
  Name and identifier records.

- [`eulob_search()`](https://eulob.lobbyresearch.org/reference/eulob_search.md):
  Search organization names.

- [`eulob_cross_registers()`](https://eulob.lobbyresearch.org/reference/eulob_cross_registers.md):
  Shared names across registers.

- [`eulob_info()`](https://eulob.lobbyresearch.org/reference/eulob_info.md):
  Project metadata.

- [`eulob_version()`](https://eulob.lobbyresearch.org/reference/eulob_version.md):
  Package version.
