# Information About the EU-LOB Database

Returns basic information about the EU-LOB project and the installed R
package.

## Usage

``` r
eulob_info()
```

## Value

A named list containing project metadata.

## Examples

``` r
eulob_info()
#> $project
#> [1] "EU-LOB"
#> 
#> $full_name
#> [1] "An Open and Incremental Database of Registered Lobbying Organizations in the European Union"
#> 
#> $package
#> [1] "eulob"
#> 
#> $version
#> [1] "0.2.1.9000"
#> 
#> $repository
#> [1] NA
#> 
#> $data_version
#> [1] NA
#> 
```
